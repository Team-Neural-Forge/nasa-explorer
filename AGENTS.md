# Project Instructions

AI configuration rules for this project live in the rule files below. Load them when relevant to the task at hand.

## Rule files

- `.opencode/rules/structure.md` — project structure and file/folder naming
- `.opencode/rules/variable.md` — variable naming conventions
- `.opencode/rules/libreoffice.md` — **only** for LibreOffice MCP operations
- `.opencode/rules/obsidian.md` — **only** for Obsidian MCP operations
- `.opencode/rules/env_example.md` — keep `.env.example` in sync with env-related code
- `.opencode/rules/git_workflow.md` — commit, PR, checks, and merge flow
- `.opencode/rules/responsiveness.md` — always plan for responsive frontend UI
- `.opencode/rules/approval.md` — ask for user approval before commit/push/PR/merge after code changes

Kilocode loads the same rules from `.kilo/rules/`.
Claude Code loads the same rules from `.claude/rules/` (via `CLAUDE.md` → `@AGENTS.md`).

## Scope notes

- LibreOffice and Obsidian rules apply only during those MCP operations. All related files must be created inside the `nasa-space-app-challenge` directory with purpose-suitable names.
