# Frontend Responsiveness Rule

Whenever you build or change frontend UI, always plan for responsiveness:

1) Design for mobile, tablet, and desktop — not just one screen size
2) Prefer fluid layouts (flexbox, grid, relative units) over fixed widths
3) Consider common breakpoints when adding or moving UI elements
4) Ensure touch targets and spacing work on small screens
5) Verify new UI does not overflow or break at narrow widths
